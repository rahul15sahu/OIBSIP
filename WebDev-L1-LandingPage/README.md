# Creative Studio Landing Page

A modern, responsive landing page for a fictional creative agency. This project showcases a clean hero section, navigation bar, service cards, and contact section built using only HTML and CSS.

## Overview

This landing page is designed to present a creative studio brand in a polished and professional manner. It is fully responsive and suitable for personal portfolios, agency websites, or portfolio mockups.

## Features

- Responsive layout for desktop and mobile devices
- Navigation links for Home, Services, and Contact sections
- Eye-catching hero section with a call-to-action button
- Service cards for design, development, and creative strategy
- Contact information section and footer
- Lightweight implementation with no external libraries required

## Tech Stack

- HTML5
- CSS3

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd WebDev-L1-LandingPage
```

3. Open `index.html` in your browser.

You can also use a live preview extension such as VS Code Live Server for a smoother development experience.

## Customization

To personalize the landing page:

- Replace the studio name and tagline in `index.html`
- Update the navigation labels and content blocks
- Change the contact email and footer text
- Modify the color palette and spacing in the embedded CSS
