# Temperature Converter Website

A simple and responsive temperature conversion web app built with HTML, CSS, and JavaScript. The app allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with instant results and validation.

## Overview

This project is a beginner-friendly web development task that demonstrates form handling, unit conversion logic, and user-friendly UI design. It includes input validation to prevent invalid entries and checks for values below absolute zero.

## Features

- Convert between Celsius, Fahrenheit, and Kelvin
- Real-time validation for invalid or empty input
- Prevents temperatures below absolute zero
- Clear button to reset the form
- Responsive card-based layout
- Lightweight and easy to run locally

## Tech Stack

- HTML5
- CSS3
- JavaScript

```bash

```

2. Open the project folder:

```bash

```

3. Open `index.html` in your browser.

You can also open it with a live preview extension such as VS Code Live Server for a smoother experience.

## How It Works

- Enter a numeric temperature value.
- Select the source unit from Celsius, Fahrenheit, or Kelvin.
- Select the target unit.
- Click the Convert Temperature button.
- The app converts the value using the appropriate formulas and displays the result.

## Validation Rules

- Empty or invalid input shows an error message.
- Values below absolute zero are rejected.
- The result is formatted to two decimal places.

## Customization

To customize the app:

- Edit the page title and headings in `index.html`
- Change the color theme and layout styles in the CSS section
- Update the conversion logic or validation messages in the JavaScript section
