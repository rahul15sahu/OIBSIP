# Rahul Sahu | Backend Developer Portfolio

A sleek and responsive personal portfolio website built with HTML and CSS. This project showcases Rahul Sahu's professional profile, technical skills, academic background, projects, certifications, and contact information in a modern dark theme.

## Overview

This portfolio is designed for developers who want a clean, professional online presence without relying on frameworks or external libraries. It highlights backend development experience, engineering interests, and key project work in a visually appealing one-page layout.

## Features

- Responsive single-page portfolio layout
- Sticky navigation bar with smooth scrolling
- Hero section with personal branding and CTAs
- About section with background and career objective
- Technical skills cards
- Project showcase section
- Education timeline
- Certification and extracurricular activities
- Contact section with email, phone, and LinkedIn link
- Clean dark theme with blue accent colors

## Tech Stack

- HTML5
- CSS3
- JavaScript not required for core layout

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd WebDev-L1-PersonalPortfolio
```

3. Open `index.html` in your browser.

You can also use a local preview extension such as VS Code Live Server for a better viewing experience.

## Customization

To personalize the portfolio:

- Update the name, title, and introduction in `index.html`
- Replace contact details, email, and LinkedIn link
- Edit project descriptions, education details, and certifications
- Modify the color palette and typography in the embedded CSS

## File Details

- `index.html` contains the complete page structure and inline styling
- `README.md` provides project documentation for GitHub
